# ApprovalGuard backend API

Start from this folder with `python api.py`. The default address is
`http://127.0.0.1:8091`. FFmpeg must be installed and available on `PATH`.

## `GET /api/health`

Returns service readiness and schema version.

## `POST /api/analyze`

Send `multipart/form-data` with:

- `file`: WAV, FLAC, MP3, M4A, MP4, MOV, WebM or MKV; maximum 250 MB.
- `context`: optional JSON object, retained as case metadata but never used to
  change neural model scores.

Example:

```bash
curl -X POST http://127.0.0.1:8091/api/analyze \
  -F 'file=@sample.mp4' \
  -F 'context={"workflow":"payment_approval","case_id":"DEMO-001"}'
```

The response separates `signals.voice_ai`, `signals.visual_ai`, and
`signals.lip_sync`. `review.priority_index` is a queue-routing index, not a
fraud probability. `review.level` is generated by an explicit decision table:
two high signals escalate, one high signal or two elevated signals require
review, otherwise standard controls continue. Insufficient quality produces an
abstention-style response.

Model loading can download the official torchvision ResNet-18 ImageNet weights
once on first start. AASIST and the DeepfakeBench Meso4 face-manipulation
checkpoint are bundled locally and documented in `THIRD_PARTY_MODELS.md`.

## Response outline

```json
{
  "media": {"duration_s": 5.0, "has_audio": true, "has_video": true},
  "quality": {"audio_sufficient": true, "video": {"sufficient": true}},
  "signals": {
    "voice_ai": {"available": true, "score": 72.1, "segments": []},
    "visual_ai": {"available": true, "score": 48.3, "timeline": []},
    "lip_sync": {"available": true, "score": 31.0}
  },
  "review": {
    "level": "REVIEW",
    "action": "Require independent reviewer verification",
    "priority_index": 60.2,
    "priority_is_probability": false
  }
}
```

Scores are evidence scales for this prototype, not calibrated probabilities.
